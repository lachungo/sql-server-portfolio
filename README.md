## SQL Server Flight Recorder Architecture

The Agentic AI RCA Toolkit connects investigation layers that are often analyzed separately:

**Time window → Database scope → Sessions → Executions → Runtime parameters → Execution plans → Resource pressure → Causal relationships → Evidence-backed conclusion**

The toolkit currently demonstrates:

- Target-database scoping for I/O and transaction-log evidence
- Scheduled Extended Events capture
- Persisted diagnostic evidence
- Captured actual-plan parsing
- Runtime-parameter extraction
- Execution-to-plan fallback linkage
- Multi-domain candidate generation and arbitration
- Timestamped HTML reporting
- Atomic deployment patterns for correction scripts

The repository also distinguishes clearly between demonstrated capability and remaining production-hardening requirements.
